# Как пользоваться помощником по инструкциям 1С

Пошаговая инструкция для новичка. Командную строку знать не нужно: всё запускается двойным щелчком.

## Что это и как работает, в двух словах

Вы складываете инструкции в папку. Человек задаёт вопрос своими словами, например «не грузится эксель». Помощник находит в инструкциях подходящий кусок и отвечает по нему. Если ответа в инструкциях нет, он так и говорит.

Без Claude помощник показывает найденный кусок инструкции как есть. С Claude он пишет нормальный ответ по шагам и указывает, из какой инструкции взял.

## Где всё лежит

Всё лежит в папке `bot`.

| Что | Зачем |
|---|---|
| `0-Установить.cmd` | Ставит нужные библиотеки. Нужен только на новом компьютере |
| `1-Задать-вопрос.cmd` | Окно, где можно задавать вопросы |
| `2-Проверить-качество.cmd` | Показывает, что в базе, и проверяет, как хорошо ищет |
| `3-Запустить-Telegram-бота.cmd` | Запускает бота в Telegram |
| `docs\` | **Сюда кладёте инструкции** |
| `docs\private\` | Сюда — инструкции компании, которые нельзя показывать посторонним |
| `.models\`, `.cache\` | Служебные папки, не трогайте |

---

## Шаг 1. Установка

1. Установите Python с сайта python.org. При установке поставьте галочку **«Add python.exe to PATH»**.
2. Скачайте репозиторий целиком.
3. Дважды щёлкните `bot\0-Установить.cmd` и дождитесь надписи `OK`.
4. Скопируйте `1c-tools\.env.example` в `1c-tools\.env` и впишите путь к базе и пользователя 1С с правами только на чтение.
5. Скопируйте `bot\allowed_users.example.txt` в `bot\allowed_users.txt` и впишите свой Telegram ID.

## Шаг 2. Задать первый вопрос

1. Дважды щёлкните `1-Задать-вопрос.cmd`. Откроется чёрное окно.
2. После значка `>` напишите вопрос, например `где отчёт по залежавшимся товарам`, и нажмите Enter.
3. Чтобы выйти, нажмите Enter на пустой строке или просто закройте окно.

Первый запуск может занять минуту: помощник загружает модель поиска по смыслу. Дальше он отвечает быстро.

Пока Claude не подключён, ответ начинается со слов «(Нейросеть не подключена)», и вы видите кусок инструкции как есть. Это нормально.

## Шаг 3. Добавить свои инструкции

1. Положите файл в папку `docs`. Если инструкция внутренняя, для компании, — в `docs\private`.
2. Подходят форматы: **Word (.docx), PDF, .md, .txt**.
3. Закройте окно с вопросами и откройте его снова. Новые инструкции подхватятся сами, больше ничего делать не нужно.

Как писать инструкции, чтобы помощник хорошо находил ответы:
- **Делите текст на разделы с понятными заголовками.** Помощник ищет кусками по разделам, и заголовок для него — главная подсказка. Хороший заголовок: «Как загрузить счета из Excel». Плохой: «Раздел 3».
- В Word делайте заголовки через стили «Заголовок 1» и «Заголовок 2», а не просто жирным шрифтом.
- Один раздел — одна тема. Лучше несколько коротких разделов, чем одна длинная простыня.
- Пишите теми словами, какими спрашивают пользователи: «кнопка не видна», а не только «команда недоступна».
- **PDF-сканы (фотографии страниц) не подойдут:** в них нет текста, только картинка. Нужен PDF, в котором текст можно выделить мышкой.

Проверить, что инструкция попала в базу: запустите `2-Проверить-качество.cmd`. В первых строках будет список файлов и сколько кусков из каждого получилось.

## Шаг 4. Подключить Claude (чтобы были нормальные ответы)

Это платно: оплата за каждый запрос. Один ответ стоит доли рубля, но счёт нужно пополнить.

**Получить ключ:**
1. Зайдите на console.anthropic.com и зарегистрируйтесь.
2. Пополните баланс в разделе Billing.
3. В разделе API Keys нажмите Create Key и скопируйте ключ. Он начинается с `sk-ant-`.

**Сохранить ключ.** Ключ — как пароль: не присылайте его в чат и не сохраняйте в файлы. Положите его в хранилище паролей Windows:
1. Нажмите «Пуск», наберите **«Диспетчер учётных данных»** и откройте его.
2. Выберите **«Учётные данные Windows»**.
3. Нажмите **«Добавить общие учётные данные»**.
4. Заполните поля:
   - Адрес в Интернете или сети: `RAG1C_Anthropic`
   - Имя пользователя: любое, например `key`
   - Пароль: вставьте ключ
5. Нажмите «ОК».

**Проверить:** запустите `2-Проверить-качество.cmd`. В строке «Claude API» должно быть «подключён». Теперь в `1-Задать-вопрос.cmd` ответы будут человеческим текстом.

## Шаг 5. Telegram-бот

**Создать бота:**
1. В Telegram откройте @BotFather и отправьте `/newbot`.
2. Придумайте имя бота, например «Помощник 1С».
3. Придумайте адрес бота. Он должен заканчиваться на `bot`, например `pomoshnik_1c_bot`.
4. BotFather пришлёт токен — длинную строку вида `123456789:AAH...`. Это тоже пароль.

Создайте отдельного бота: если один бот запущен в двух местах, они мешают друг другу.

**Сохранить токен** так же, как ключ в шаге 4, только в поле адреса напишите `RAG1C_TelegramBot`, а в поле пароля вставьте токен.

**Запустить:** дважды щёлкните `3-Запустить-Telegram-бота.cmd`. Если появилась надпись «Бот запущен», откройте своего бота в Telegram, нажмите «Старт» и задайте вопрос.

Бот работает, **пока открыто это окно и включён компьютер**. Закрыли окно — бот замолчал. Чтобы бот работал круглосуточно, его нужно перенести на сервер; с этим помогу отдельно.

## Вопросы по данным 1С (долги, продажи, склад)

Бот подключается к базе 1С:Бухгалтерии и на каждый вопрос делает свежий запрос: в ответ попадает всё, что проведено к этой минуте. Старые выгрузки он не использует. Подключение идёт под отдельным пользователем 1С, которому можно только читать: изменить что-либо в базе бот не может.

| Спросите | Что ответит |
|---|---|
| кто нам должен? / дебиторка | Общий долг покупателей, список должников, сколько просрочено |
| сколько должен Ромашка? | Долг одного покупателя с разбивкой по документам |
| просроченные долги | Только просроченное, с числом дней |
| долги на 1 ноября / на 01.11.2026 | Долг на конец этого дня |
| продажи за октябрь / за прошлый месяц / за 2025 год / с 01.02 по 15.02 | Сумма продаж и список покупателей |
| остаток фильтр масляный | Сколько товара на складе и на какую сумму |
| залежавшиеся товары / не продаются больше 180 дней | Что давно лежит без продаж |

Как бот считает:
- **Долг** — остаток по счёту 62. Непроведённые документы в долг не попадают, и бот об этом предупреждает.
- **Просрочка** — по сроку оплаты из договора. Если срок в договоре не задан, просрочка считается с даты реализации. Просрочку бот считает только по реализациям: списания с расчётного счёта и прочие суммы показывает, но просроченными не помечает.
- **Переплаты и авансы покупателей** показаны отдельно и в сумму долга не входят.
- Вопросы, которые начинаются с «как», «где», «почему», «что значит», а также вопросы про ошибки, отчёты, загрузку и настройку — это вопросы по работе в 1С. На них бот отвечает по инструкциям.

Бот видит только ту базу, путь к которой записан в `1c-tools\.env`. Если за запрошенный период продаж нет, бот так и скажет и назовёт дату последней реализации в базе.

## Кто может пользоваться ботом

Бот отвечает только тем, чей Telegram ID записан в файле `allowed_users.txt`, по одному в строке. Остальным бот отвечает «Нет доступа» и показывает их ID. Чтобы дать доступ коллеге:
1. Коллега пишет боту `/myid` и присылает вам свой номер.
2. Вы дописываете этот номер новой строкой в `allowed_users.txt`.
3. Перезапускать бота не нужно.

Помните: кому вы дали доступ, тот видит долги и продажи из базы.

## Шаг 6. Проверка качества

`2-Проверить-качество.cmd` прогоняет заранее заготовленные вопросы и показывает:
- **hit@1** — в скольких вопросах нужная инструкция нашлась первой. Чем ближе к максимуму, тем лучше.
- **отвечает по теме** — на сколько нормальных вопросов помощник взялся отвечать, а не сказал «нет в инструкциях».
- **не по теме** — что он делает с посторонними вопросами: отказ (хорошо), серая зона (решает Claude), уверенно-ложно (плохо).

Тестовые вопросы написаны под мои 4 инструкции. Когда добавите свои, напишите мне. Я добавлю вопросы по ним, чтобы проверка оставалась честной.

## Если что-то не работает

| Что видите | Что делать |
|---|---|
| Окно открылось и сразу закрылось, или ошибка «python не является командой» | Python не установлен или не добавлен в PATH. Переустановите Python с галочкой «Add python.exe to PATH» (шаг 1) |
| `ModuleNotFoundError` | Не установлены библиотеки. Запустите `0-Установить.cmd` |
| «Нейросеть не подключена», хотя ключ сохранили | Проверьте, что адрес в Диспетчере учётных данных — ровно `RAG1C_Anthropic`, а ключ лежит в поле «Пароль» |
| «Ошибка Claude API 401» | Ключ неверный или удалён. Создайте новый и сохраните заново |
| «Ошибка Claude API 400» с текстом про credit/balance | Закончились деньги на балансе Anthropic |
| «Нет токена бота» | Токен не сохранён или адрес написан не так. Нужно ровно `RAG1C_TelegramBot` |
| Бот в Telegram молчит | Проверьте, что окно `3-Запустить-Telegram-бота.cmd` открыто и в нём нет ошибок |
| Бот отвечает «Нет доступа» | Вашего ID нет в `allowed_users.txt`. Напишите боту `/myid` и добавьте номер в файл |
| «Не получилось получить данные из 1С» | База недоступна: её перенесли, на ней идёт обновление или открыт Конфигуратор в монопольном режиме. Проверьте и спросите ещё раз |
| Помощник не находит то, что точно есть в инструкции | Проверьте, что раздел назван понятно (шаг 3). Пришлите мне вопрос и файл, разберёмся |

## Что дальше

- **Выложить на GitHub для портфолио.** Помогу подготовить. Папки `docs\private`, `.models` и `.cache` туда не попадут: они исключены настройками.
- **Перенести бота на сервер**, чтобы он работал круглосуточно.
