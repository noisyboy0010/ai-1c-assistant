# Установка и обновление расширений 1С

Инструкция для администратора базы. Расширения — это доработки, которые не меняют типовую конфигурацию. Поэтому базу можно обновлять как обычно, а расширения остаются.

## Как установить расширение (.cfe)

1. Откройте 1С в режиме «Предприятие» под пользователем с полными правами.
2. Откройте «Администрирование» → «Печатные формы, отчеты и обработки» → «Расширения».
3. Нажмите «Добавить из файла» и выберите файл .cfe.
4. Перезапустите 1С. Новое расширение появляется у пользователей только после перезапуска.

Если загружать расширение через Конфигуратор или командой, Конфигуратор с этой базой должен быть закрыт. Пока он открыт, загрузка блокируется.

## Безопасный режим

У расширения «ЗагрузкаИзExcel» нужно снять флажок «Безопасный режим» в списке расширений. Платформа 1С читает файлы xlsx только с диска, а в безопасном режиме расширению запрещено создавать временные файлы. Без этого загрузка падает с ошибкой «Не удалось сохранить временный файл».

Отчёту «Залежавшиеся товары» безопасный режим не мешает.

## Почему не видно команды расширения

- 1С не перезапускали после установки. Перезапустите.
- У пользователя нет роли расширения. Проверьте права пользователя.
- Команду ищут в форме списка документов. В БП 3.0 формы списков не показывают команды расширений, поэтому наши команды лежат в разделах: загрузка счетов — «Продажи» → «Сервис», отчёт — «Склад» → «Отчеты».

## Обновление расширения

Удалять старую версию не нужно. В списке расширений выберите расширение и загрузите новый файл .cfe поверх, затем перезапустите 1С.
