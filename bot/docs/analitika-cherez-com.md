# Аналитика 1С через COM-соединение

Утилита onec.py позволяет получать данные из базы 1С без открытия программы: выполнять запросы и сохранять результат в CSV, а затем открывать в Excel.

## Что нужно для работы

- Windows и установленная платформа 1С той же версии, что и база.
- Зарегистрированная COM-компонента comcntr.dll (V83.COMConnector).
- Пользователь 1С с ролью «Запуск внешнего соединения». Для аналитики лучше завести отдельного пользователя с правами только на чтение.
- Python 3 с пакетами pywin32 и python-dotenv.
- Файл .env рядом со скриптом: путь к базе (ONEC_BASE), пользователь (ONEC_USER) и пароль (ONEC_PWD). Этот файл нельзя выкладывать в интернет и передавать другим.

## Основные команды

- `python onec.py ping` — проверить, что соединение с базой работает.
- `python onec.py meta Documents` — список документов конфигурации. Вместо Documents можно указать Catalogs (справочники) и другие виды объектов.
- `python onec.py query "ВЫБРАТЬ ПЕРВЫЕ 10 Наименование ИЗ Справочник.Контрагенты"` — выполнить запрос.
- `python onec.py query -f queries\файл.txt --csv out\результат.csv` — выполнить запрос из файла и сохранить результат в CSV.

## Готовые запросы

- Дебиторская задолженность (счёт 62): по каждому покупателю, договору и документу расчётов показывает сальдо и срок оплаты по договору. Файл queries\debitorka_62.txt.
- Залежавшиеся товары: остаток на счёте 41 и даты последнего прихода и расхода по каждой позиции. Файл queries\zalezhavshiesya.txt.

## Если COM перестал работать

Чаще всего это происходит после обновления платформы 1С: компонента остаётся зарегистрированной от старой версии. Нужно заново зарегистрировать comcntr.dll из каталога новой версии платформы (от имени администратора) и проверить, что в реестре путь библиотеки типов указывает на новую версию.

Ошибка доступа при подключении обычно значит, что у пользователя нет роли «Запуск внешнего соединения».

## Особенности запросов

- Символ «[» в условии ПОДОБНО нужно экранировать через СПЕЦСИМВОЛ.
- Справочник «Виды номенклатуры» в БП 3.0 не иерархический, условие В ИЕРАРХИИ к нему не применяется.
